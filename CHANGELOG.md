# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-11-18
### Added
- Multimodal spatial data lakehouse engine with Apache Iceberg open table partitioning.
- LakeFS-compatible immutable dataset branching, commits, and end-to-end lineage tracking.
- Bronze-to-Gold atomic ingest pipeline with SHA-256 checksum validation and content-addressed deduplication.
- WebDataset and MosaicStreaming GPU training shard loader with zero-bubble chunk prefetching.
- Automated small-file compaction planning to prevent object storage latency degradation.

## [0.1.0] - 2026-11-01
### Added
- Initial reference data platform with DuckDB, Spark, Airflow, and FastAPI endpoints.
